# Features
- ## Languages
- Arabic
- English
- French
- Coptic (Coming Soon)

- ## UI
- Streak counter
- Dark/Light mode
- Verses with different types and options
- verses counter
- Favorite verses
-
- ## Tabs
-  Read (Tab) 
- Sermons (Tab)
- Updates (Tab)
- About (Tab)
- Book (Bible (Tab))
- Note-Book (Tab)
